# Jericho Grannies

Official football website for Jericho Grannies.

## About

Jericho Grannies is a community football project celebrating friendship, football, active living and the lasting power of community.

The website provides a digital home for:

- The team
- Fixtures and results
- Team stories
- Photo gallery
- Community support and contact information

## Technology

- React
- TypeScript
- Vite
- React Router
- Bootstrap
- Bootstrap Icons
- oxlint

## Frontend

The frontend application is located in `frontend/`.

## Development

```bash
cd frontend
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## Project Status

The website foundation and primary public pages are implemented. Official team media, player profiles, fixtures, results and contact information can be added as verified club information becomes available.
